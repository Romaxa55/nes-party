NES Party

NES classics for two over the internet: one player hosts the game, the other joins with a code from their phone. No installs — just a browser.

Host a game Load your .nes file, get a room code and send the link to a friend. Emulation runs on your device — a laptop works best. Join with a code Enter the code from the host — you get the game screen and a touch gamepad right on your phone. No game file needed. Device benchmark Check whether this device can emulate the NES at a steady 60 fps. Useful before hosting from a phone.

No game images are distributed with this project: the .nes file is picked on the host's device and never uploaded anywhere — only the video stream and button presses travel over the network.
